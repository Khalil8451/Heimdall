# Support

API Archaeologist currently provides repository tooling and synthetic fixtures, not a supported running product. Start with the public [README](README.md) and [contributor setup](CONTRIBUTING.md). Team planning documents are maintained separately and are not publicly distributed.

For a tooling bug, provide OS, Node/npm versions, exact command, sanitized output and a minimal synthetic reproduction. Do not copy private planning tickets, contracts, source or credentials into public issues. Use [SECURITY.md](SECURITY.md) for vulnerabilities.

No hosted service, paid support, guaranteed response time or production SLA is offered.
